Other MacsAndere Macs

One office for all your Macs.Ein Büro für alle deine Macs.

Pair your Macs with a code and the sessions running on the others show up in the menu and in the office, marked with a small device symbol. Discovery via Bonjour on your local network, every message encrypted with the pairing code.Koppel deine Macs per Code, und die Sitzungen der anderen erscheinen im Menü und im Büro, markiert mit einem kleinen Geräte-Symbol. Gefunden wird per Bonjour im lokalen Netzwerk, jede Nachricht ist mit dem Code verschlüsselt.

  1. Turn on Other Macs in Settings and enter the same pairing code on every Mac.
  2. Wait a moment. A Mac only answers after the other side has proved it knows the code.
  3. That's it. Only status, project, title and activity of sessions are shared, never files or logs.
  4. Andere Macs einschalten in den Einstellungen und auf jedem Mac denselben Kopplungscode eintragen.
  5. Kurz warten. Ein Mac antwortet erst, wenn die Gegenseite bewiesen hat, dass sie den Code kennt.
  6. Fertig. Geteilt werden nur Status, Projekt, Titel und Tätigkeit der Sitzungen, nie Dateien oder Protokolle.

SetupEinrichten

Set up in a minute.In einer Minute eingerichtet.

InstallInstallieren

No account, no installer. Just the app.Kein Konto, kein Installer. Nur die App.

  1. Download AgentBar.zip from the latest release, unzip it and move AgentBar.app to /Applications.
  2. Allow the first launch. AgentBar isn't notarized by Apple, so macOS blocks it once. Open System Settings, Privacy & Security and click Open Anyway, or run this in Terminal:
  3. Laden: AgentBar.zip aus dem neuesten Release, entpacken und AgentBar.app in den Ordner Programme ziehen.
  4. Ersten Start erlauben. AgentBar ist nicht von Apple notarisiert, deshalb blockiert macOS den ersten Start. Öffne Systemeinstellungen, Datenschutz & Sicherheit und klicke Trotzdem öffnen, oder im Terminal:
xattr -dr com.apple.quarantine /Applications/AgentBar.app
  1. Turn on precise detection. Click Set up on the Precise detection card in the menu. AgentBar adds small hook commands to ~/.claude/settings.json (with a backup). They only append status lines to a local file.
  2. Done. Allow notifications when asked, optionally turn on Launch at login, and press ⌃⌥A for the office.
  3. Präzise Erkennung einschalten. Klick im Menü bei Präzise Erkennung auf Einrichten. AgentBar trägt kleine Hook-Befehle in ~/.claude/settings.json ein (mit Sicherung). Sie schreiben nur Statuszeilen in eine lokale Datei.
  4. Fertig. Mitteilungen erlauben, wenn gefragt wird, optional Beim Anmelden starten einschalten, und mit ⌃⌥A das Büro öffnen.

Only the first launch needs the Gatekeeper step. Later updates arrive through the built-in update window and are verified with an Ed25519 signature, bundle ID, version and code signature.Nur der erste Start braucht den Gatekeeper-Schritt. Spätere Updates kommen über das eingebaute Update-Fenster und werden per Ed25519-Signatur, Bundle-ID, Version und Code-Signatur geprüft.

PrivacyDatenschutz

It stays on your Mac.Es bleibt auf deinem Mac.

Local files only.Nur lokale Dateien.

AgentBar reads Claude Code's session logs, the Claude desktop metadata and its own hook log. No analytics, no telemetry.AgentBar liest die Sitzungsprotokolle von Claude Code, die Metadaten der Claude-App und das eigene Hook-Log. Keine Analyse, keine Telemetrie.

The token is only read.Das Token wird nur gelesen.

For the usage rings AgentBar reads Claude Code's login from the keychain and sends it only to Anthropic. It is never refreshed, modified or stored elsewhere.Für die Kontingent-Ringe liest AgentBar den Login von Claude Code aus dem Schlüsselbund und schickt ihn nur an Anthropic. Er wird nie erneuert, verändert oder woanders gespeichert.
